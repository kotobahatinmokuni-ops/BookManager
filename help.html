1.本の追加、編集、削除、フォルダ移動、開く

　1-1　本の追加

　　メニューの「追加」かメイン画面の空白部分を右クリック
　　フォルダを右クリック→「このフォルダへ本の追加」

　1-2　本の編集

　1-3　本の削除

　　◆メニューの「削除」か本を選択して右クリック
　　　※注意！ 対象画像も一緒に削除されます。
　　◆本の一括削除
　　　エクスプローラーと同じ様に複数のファイルを選択することができます
　　　※注意！ 対象画像も一緒に削除されます。

　1-4　本のフォルダ移動

　　◆3つの移動方法があります
　　・ドロップ＆ドラッグでフォルダに移動
　　・本を右クリックからフォルダへ移動
　　・編集からフォルダを選択

　1-5　本を開く

　　◆本をダブルクリックで編集で設定した方法で開きます
　　・URL(既定)
　　・フォルダを開く
　　・ファイルを開く(動作はWindows依存)

　1-6　本を完結済にする

　　◆追加・編集画面で完結済にチェック
　　チェックを入れることでタイトルの先頭に[完結]の文字が追加されます。

2.フォルダ機能・ブックカウント

　2-1　フォルダ機能

　　◆ツリー形式でのフォルダ管理が可能
　　　「すべて」ですべての本が確認できます
　　　「未分類」でフォルダに入っていない本が確認できます
　　◆フォルダの作成、移動、削除
　　・メニューバーの編集からかフォルダツリー画面の空白部分を右クリックでフォルダ作成
　　・フォルダ作成後、該当フォルダを右クリック→新規サブフォルダで子フォルダを作成可能
　　・フォルダをドロップ＆ドラッグでフォルダの移動が可能
　　・削除したいフォルダを選んで削除。本も削除するか未分類へ移動するか選択することが可能
　　◆フォルダ名の変更
　　変更したいフォルダを選んで右クリック→フォルダ名の変更
　　◆フォルダを完結済表示にする
　　変更したいフォルダを選んで右クリック→このフォルダを完結済にする
　　　　・フォルダ内の本も完結済にする
　　　　・フォルダのみを完結済にする
　　　　・階層すべてを完結済にする
　　　の3種類あります。
　　　完結済にしたフォルダはタイトルの先頭に[完結]の文字が入りチェックマークがアイコンに付きます
　　◆フォルダの完結表示の解除
　　[完結]表示されたフォルダを選んで右クリック→完結済を解除する
　　　　・このフォルダの完結済を解除する
　　　　・フォルダ内の本も含めて解除する
　　　　・階層すべての完結済を解除する
　　　の3種類あります。

　2-2　ブックカウント

　　フォルダ横の数字は登録された本の冊数です。
　　子フォルダがある場合は子フォルダも含めた冊数になります。
　　画面左下に現在選択した本の冊数が表示されます。
　　画面右下にはBookManagerに登録した本の冊数の内訳が表示されます。
　　登録済:◯册（読了:◯册　未読:◯册　読書中:◯册　未購入:◯册　保留:◯册)

　2-3　未分類の本を自動で振り分け機能

　　未分類の本のフォルダを右クリックすると
　　未分類の本に保存されている本を自動でフォルダに振り分けることができます。
　　※フォルダの自動振り分けはタイトルの一致で行います。
　　　　・第1優先:フォルダ名とタイトルが同じ
　　　　・第2優先:同じタイトルの本が存在するフォルダ
　　　空白、半角等の揺らぎに対応。振り分け出来ない本は未分類に残ります。

3.検索機能、並び替え

※各種検索機能は組み合わせることが可能

　3-1　通常検索

　　◆よくある検索機能。
　　　検索対象は
　　・タイトル
　　・シリーズ
　　・著者
　　・出版社
　　・掲載誌/レーベル
　　・サービス
　　・メモ
　　◆検索履歴
　　　検索ワードを記入後にエンターを押すと履歴に残ります
　　◆検索履歴の削除
　　　検索履歴横のゴミ箱アイコンを押すことで履歴の削除が可能

　3-2　タグ検索

　　タグのみを対象した検索

　3-3　出版社検索

　　出版社のみを対象した検索

　3-4　掲載誌/レーベル検索

　　掲載誌/レーベルのみを対象した検索

　3-5　状態検索

　　◆以下の状態の本を検索
　・読了
　・未読
　・読書中
　・未購入
　・保留

　3-6　サービス検索

　　電子書籍サービス・紙本・自炊本のみの検索

　3-7　お気に入り

　　「お気に入り」にチェック入れた本だけ検索

　3-8　並び替え

　　検索バーの並び替えとメイン画面の各項目をクリックすることで利用可能
　　※注意！巻数の並び替えのみシリーズ+巻数での並び替えになります。

　3-9　検索結果のクリア

　　「検索結果のクリア」を押すことで検索条件をクリアできます。

4.表示・テーマ

　4-1　表示

　　メニューバーの表示から詳細表示でのメイン画面の項目の表示/非表示が選択できます。

　4-2　テーマ

　　メニューバーの表示のダークモードにチェックを入れることでダークテーマに変更
　　ライトモードに戻したい場合はチェックを外してください。

　4-3　メイン画面の表示

　　詳細・小アイコン・中アイコン・大アイコン・特大アイコンから選択できます

5.未使用画像の削除

　メインメニューのツールから使用していない画像の削除ができます。
　BookManagerフォルダのimageフォルダが対象です。

6.インポート、エクスポート

　6-1　CSV、JSON、SQlite(データベース)、蔵書庫バックアップの違いについて

　　◆BookManagerのデータ交換は、次の4方式を扱います。
| 方式 　　　　　　  | 主な用途                   　　　　　　  | 特徴         　　　　　|
| CSV   　　　　　　 | 表計算ソフト等とのデータ交換・大量編集   | 人間が編集しやすい 　  |
| JSON   　　　　　　| BookManager間のデータ交換・大量編集 　　 | 構造を保持しやすい   　|
| SQLite　　　　　　 | データベース全体の移行・バックアップ 　　| 本のデータベースの復元 |
| 蔵書庫バックアップ | 蔵書庫と各種設定全体のフルバックアップ 　　| BMへの完全復帰　　　|

　6-2　エクスポートの種類

　　エクスポートはCSV、JSONの2種類が選択できます。
　　両方とも画像も含めてエクスポートされます。

　6-3　インポートについて

　　インポートにはインポート(エクスプローラーモード)とインポート(自動振り分けモード)があります。
　　CSV・JSONどちらのファイルも両方式で扱えます。
　　◆簡単な違いは以下です。
　　　◯上書き保存感覚で本を追加・更新したい → インポート(エクスプローラーモード)
　　　◯フォルダへ自動で振り分けながら本を追加・更新したい → インポート(自動振り分けモード)
　　　◯BookManagerのデータベース全体を移行・復元したい → SQLite
　　同一判定はタイトル・巻数・サービスの一致で行い、book_id は参照しません。
　・インポート(エクスプローラーモード)
　　　CSV／JSONの内容を新しい本として登録します。
　　　同じ本がすでにある場合は上書き確認が出ます（複数時は「はい・すべてはい・いいえ・すべていいえ」）。
　　　同一判定は基本的に タイトル・巻数・サービス を使用します。
　　　volume はCSV／JSONで同じ意味になるよう変換します。
　・インポート(自動振り分けモード)
　　　同名タイトルの本があるフォルダ、次に同名のフォルダへ自動で振り分けます。
　　　全角・半角文字、全角・半角スペースの違いがあっても同一判定できるようになっています。
　　　候補が複数の場合はスキップします。振り分け内容の確認後に実行します。
　　　以降の流れ（未登録フォルダ確認・上書き確認）はエクスプローラーモードと同じです。
　◆フォルダの扱い
　　フォルダは次の優先順位で決定します。
　　folder_path ＞ folder_id ＞ 未分類
　　folder_path が指定されていれば folder_id より優先します。
　　指定したフォルダが存在しない場合は、作成するか選択できます。
　　作成する場合は、必要な親フォルダを含めて階層を作成します。
　　同じ folder_path を一意に特定できない場合は、勝手に選択せずインポートを中止します。
　　folder_path がなく、folder_id も存在しない場合は未分類になります。
細かい違いはかなり長くなるので別途、インポート/エクスポート仕様書をご覧ください。
※インポート・エクスポート仕様書
　◆CSV、JSON編集方法
　　テスト用books.cvsをBookManager内に入れてあるのでそちらを参考にしてください。
　　最低限、タイトルと巻数(1巻完結なら未記入でOK)だけ入れれば登録できます。

7.SQlite(データベース)のバックアップ、復元、管理

注意！SQliteでは画像のバックアップは出来ません。あくまで本のデータのみです。
書籍を1冊ずつ変換するのではなく、データベース全体を移行・復元します。
そのため、フォルダ、タグ、書籍データなどDBに保存されている管理情報をまとめて扱えます。

　7-1　SQliteの自動バックアップ設定

　　メニューバーのツール→自動バックアップ設定から細かく設定ができます。
　　「自動バックアップを有効にする」にチェックを入れ保存先、バックアップ間隔を選んでください。
　　保存先は終了時のバックアップと共通になります。
　　注意！初期設定では自動バックアップはOFFになっています。

　7-2　終了時の自動バックアップ

　　メニューバーのツール→自動バックアップ設定から細かく設定ができます。
　　「終了時にもバックアップする」にチェックを入れ保存先、保存世代数を選んでください。
　　保存先は自動バックアップと共通になります。
　　注意！初期設定では自動バックアップはOFFになっています。

　7-2　SQliteのバックアップ、復元

　　メニューバーのツール→SQlite管理から選択できます。

　7-3　SQliteの再読み込みと整合性のチェック

　　メニューバーのツール→SQlite管理から選択できます。
　　※想定外の操作さえしなければ基本的に使うことはありません。

　7-4　初期化

　　メニューバーのツール→SQlite管理から選択できます。
　　当たり前ですが初期化されるので取り扱いは十分気をつけてください。

8.蔵書庫バックアップ

　　メニューバーのツール→蔵書庫バックアップから選択できます。
　　蔵書庫バックアップはBookManagerの設定やデータベース、画像などをまとめてバックアップすることができます。
　　各種設定、履歴、imagesフォルダの画像、「開く」で設定したローカルファイルの保存が可能ですが
　　ローカルファイルが大量にある場合は容量が膨大になるのとバックアップに時間がかかる場合があります。
　　復元する場合はリストラ(復元)からバックアップしたファイルを選択することで復元することができます。

9.API設定(ブラウザとの連携)

　APIを使用することでBookManagerを起動している時にブラウザと連携することができます。
　eBookJapan専用に未購入で他社サービスで購入した本を表示させるuserscriptが利用できます。
　詳しい利用方法はヘルプ内ローカル書籍照会APIをご覧ください。
　
　注意！
　ツール内にある「API設定」から、ブラウザとの連携を有効・無効にすることができます(デフォルトでは有効)。
　IPの変更も可能ですがAPIの仕様を理解してる方向けの設定なのでいじらないでください。
