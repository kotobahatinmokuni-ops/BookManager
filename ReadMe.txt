#電子書籍総合管理ソフト「BookManager」
#Ver5.200　　　　　　　　　　　　
#2026 09 by 404
#
#============================================================

開発環境 VScode、Python、SQlite
※このソフトは基本部分ChatGPT、追加機能・ブラッシュアップはcopilot free、OpenCode、LMStudio等各種AI、AIエージェントソフトを駆使して作成しました。

●はじめに
プログラム知識0の俺がAIに頼んで電書管理ソフトを作ってもらったら「この機能入れたら便利ですよ？」と言われ、
言われるままに機能を追加し続けたら「これなら公開できますよ」と言われた件に関して

●特徴
・エクスプローラーライクで直感的に使える操作性とフォルダ管理で電書を整理可能
・タイトル+巻数で簡単に画像登録
・タイトル以外にも
　　シリーズ
　　巻数
　　著書
　　出版社
　　掲載誌/レーベル
　　電子書籍サービス
　　URL
　　タグ機能
　　評価
　　お気に入り
　　メモ
　の項目で本の管理が可能
・多種多様の検索機能
・本を開く方法は3種類
　　URLで開く
　　フォルダで開く
　　指定ファイルを開く(開くソフトはWindows依存)
・CSV、JSONでのインポート/エクスポートに対応。大量の本を登録することが可能
・SQlite(データベース)のバックアップと復元にも対応
・API利用でScriptを作成可能

●使用方法
　BookManager.zipを解凍してBookManager.exeを起動してください。

●使い方
　ヘルプを確認してね。
